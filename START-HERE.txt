RICHMOND MOTOR CLUB — CONTINUOUS SCORING LOG

UPDATE
Extract this ZIP and replace the files in the existing Richmond app website/project. Keep the same website address to retain locally saved scores and WebDAV settings. Open/refresh online before using offline. This package has not been deployed.
The prior Richmond app's stored scores and WebDAV URL/username are migrated on first opening this version. Enter the WebDAV password once: it is now retained on this device, including after reset.

EVENT SET UP
Section number, Multi Lap Trial checkbox, WebDAV HTTPS folder link, username and password. There are no app password locks. WebDAV login credentials are still used to authenticate uploads to your server.
CLEAR EVENT / RESET APP clears scores, section and multi-lap setting, but keeps every WebDAV setting. Clearing browser/site data will remove them.

SCORING
Rider numbers 1–300. Score buttons: 0, 1, 2, 3 on the first row; 5 and 10 on the second row.
Each score tap adds a log entry. There is no lap cap and no fixed maximum number of entries (subject to device storage).
Single lap: every entry is lap 1. Subsequent entries for the same rider at the same section are marked DUPLICATE, regardless of score value. Equal scores belonging to different riders are not duplicates.
Multi Lap Trial (in Event Set Up): repeat visits at the same section become laps 2, 3, etc. Duplicate warnings are suppressed. The checkbox applies to the complete current log and its exports.
Check All Scores Log opens a full-page chronological list. Edit changes a score while preserving its original time. Undo removes the latest score; log numbers remain stable, so gaps are possible.

SAVE & SENDING
Exactly two actions: PRINT and SEND TO WEBDAV SERVER.
Print opens the device print dialog. Choose a printer or Save as PDF where supported. Duplicate lap cells are highlighted and labelled in single-lap mode. No date is printed by the app; disable the browser's print headers/footers if it adds its own date or URL.
WebDAV sends the entire current log as a CSV with a unique filename. Successful upload marks the current entries as saved. Failure keeps the log intact and reports an error. Printing/sending never automatically deletes scores: use Clear Event after checking the saved output. Further scoring appends to the log until cleared.

CSV FORMAT
Log count, Section, Rider number, Lap, Score, Time stamp
Time is local device time in HH:MM:SS format. No date column. Only actual recorded scores are exported; no missing-score MS rows are generated.
CSV has no colour formatting. In single-lap mode duplicate lap values are written as "1 DUPLICATE". In multi-lap mode the lap values remain numeric with no duplicate label. Consumers should account for the label when importing a single-lap CSV.

WEBDAV
Use the actual HTTPS WebDAV folder endpoint, not a browser share link. The folder must exist and permit uploads. Optional Basic authentication credentials are retained locally as requested. Use a dedicated account with access only to the scores folder.
Cross-origin servers must permit the app's origin, OPTIONS/PUT methods and Content-Type/Authorization headers using CORS. No redirects, embedded URL credentials, query strings or fragments. Turn airplane mode off and connect before sending. After a timeout, check the server before retrying because the first upload may have arrived.

OFFLINE
Open the hosted app online before the event so all files are cached. Add to Home Screen and check reopening in airplane mode. Keep Screen On depends on browser/device support and battery settings. Scores save locally after every entry.
