RICHMOND MOTOR CLUB

Event Set Up and Save & Sending ask for the organiser password each time they are opened. Scoring and the full scores log remain available without it.

Set the WebDAV folder link in Event Set Up. Use Send File to choose Email, WhatsApp or WebDAV. Email and WhatsApp use your phone's share menu where supported; otherwise download the CSV and attach it manually. WebDAV needs an internet connection and browser uploads enabled on the server.

Check All Scores Log shows every current score, first entered at the top and latest at the bottom. Corrected scores keep their original position; undone scores are removed.

HELP & USER GUIDE

Set up an event, record and correct scores, then save and send each section CSV.

QUICK START EVENT SET UP SCORING SAVE & SEND TROUBLESHOOTING
QUICK START
  1. Open EVENT SET UP and enter the event, date, section, laps and observer details. The rider limit is automatically set to 300.
  2. If you are observing two sections, tick the option and enter the second section number.
  3. Open SCORING, enter a rider number, confirm the section, then tap 0, 1, 2, 3 or 5.
  4. Check the green confirmation shows the correct rider, lap, section and score.
  5. Use CHECK SCORE, CORRECT SCORE or UNDO LAST SCORE if an entry needs attention.
  6. Open SAVE & SENDING, save the CSV for the correct section, open it and check it.
  7. Send or share the checked CSV with the event secretary.
Critical export check: Before sending, confirm that the CSV contains every expected rider and lap. Missing scores must show as MS.

RECORD, CHECK & CORRECT SCORES

Record a score

  1. Open SCORING and enter the rider number.
  2. Confirm the correct section is selected.
  3. Read the current-rider panel; it shows existing scores and the next lap.
  4. Tap 0, 1, 2, 3 or 5 and verify the green confirmation.

Laps are automatic. The app counts the rider's existing entries for that section and records the next lap. It will not accept more scores than the configured number of laps.

Check, correct or undo

ControlHow to use it
CHECK SCOREEnter a rider number and review all recorded sections and laps for that rider.
CORRECT SCOREEnter the rider, section and lap, select FIND SCORE, then choose the replacement score.
UNDO LAST SCOREWith the rider and section selected, remove the most recently entered score for that rider and section.
After a change: Re-save the affected section CSV. Changing a first-section score also relocks section two until the first CSV is saved again.
WORK WITH TWO SECTIONS
  1. In EVENT SET UP, tick the two-section option and enter a different second section number.
  2. Score the first section. The second section remains locked.
  3. After at least one first-section score has been recorded, save or successfully share the first-section CSV.
  4. Return to SCORING; the second section is now available.
  5. Score the second section, then save or share its separate CSV.

Saving an empty first-section file does not unlock section two. If a first-section score is later added, corrected or undone, save that section again to unlock the second.

SAVE & SEND A SECTION CSV
  1. Open SAVE & SENDING and check the event summary.
  2. Select SAVE SCORES CSV for the required section.
  3. Open the downloaded file and check the event, section, riders, laps, scores and timestamps.
  4. Confirm every expected rider and lap is present and each unrecorded score is marked MS.
  5. Select SEND / SHARE CSV to use the device share sheet. If sharing is unavailable, attach the downloaded file manually.

Each section has its own file, named in the style Event_Name_section_4_scores.csv. Use COPY EMAIL ADDRESS to copy the saved secretary address.

RESET THE APP
  1. Save and send every required section CSV, then open each file to verify it.
  2. Return HOME and select RESET APP.
  3. Select the green tick only when the event data can be removed. Select the red X or Back to cancel.
Reset is destructive: It clears event setup, scores and saved browser data. Do not reset until every required file has been checked and sent.
