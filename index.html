Set the section number and WebDAV folder/login. Scoring supports rider numbers 1–300 with no limit on the number of log entries or laps. Every tap of 0, 1, 2, 3, 5 or 10 adds a score.

Tick Multi Lap Trial in Event Set Up to count each return of a rider at the same section as the next lap. With it unticked, repeated entries for the same rider and section show lap 1 DUPLICATE. Different riders sharing the same score are not duplicates.

The CSV contains only Log count, Section, Rider number, Lap, Score and Time stamp (HH:MM:SS). CSV cannot contain colour: duplicated lap cells contain DUPLICATE; print and onscreen views also highlight them. Multi Lap Trial suppresses duplicate marking.

Print opens the device print dialog (including Save as PDF where available). WebDAV sends the complete current log. Saving or printing does not erase scores; continue scoring or use Clear Event / Reset App to begin a new log. Reset keeps all WebDAV settings, including its password.

Use Edit beside a log entry to correct its score, or Undo Last Score to remove the latest entry. Corrections retain the original entry time. Log counts identify entries and can have gaps after undo.

Open the app online before relying on it offline. WebDAV requires an HTTPS folder with write access and, for a different server, CORS allowing this app’s origin, PUT, Content-Type and Authorization. Turn airplane mode off before sending.
